# AiChatBot · Solar Saathi

Solar Saathi is a voice chatbot for **Clans Machina**. It speaks Odia, Hindi and English and helps rooftop-solar customers through four things:

1. registration with OTP
2. location
3. qualification questions
4. a personalised solar plan, then booking a free consultation

| Folder | What's inside |
|---|---|
| [`solar-saathi/`](solar-saathi/) | The app: Next.js, TypeScript, Tailwind CSS, a 3D mascot built with three.js, and the voice engine. Setup and the full feature list are in [its README](solar-saathi/README.md). |
| [`docs/`](docs/) | The research and build plan. |

## Quick start

```bash
cd solar-saathi
npm install
cp .env.example .env.local   # add your own keys here; this file is never committed
npm run dev                  # http://localhost:3005
```
